The program contains no BIOS, no game image and no game data. You need your
own PS2 BIOS and your own copy of Fate/unlimited codes (SLPM-55108).
Fate/unlimited codes is a trademark of its owners; this project is not
affiliated with Capcom, TYPE-MOON or cavia.

The program downloads nothing, starts no other programs and does not change
Windows settings. Over the network it only exchanges controller input with
the other player during an online session. The complete source code is
public, so anyone can check this.
