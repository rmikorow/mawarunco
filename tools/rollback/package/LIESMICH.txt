Fate/unlimited codes - Online mit Rollback (Testversion)
=======================================================

Das ist ein angepasster PCSX2 (PS2-Emulator) mit Rollback-Netcode fuer
Fate/unlimited codes (PS2, SLPM-55108). Zwei Spieler verbinden sich direkt
ueber die IP-Adresse. Einer ist Host (Spieler 1), der andere verbindet sich
(Spieler 2).


1. Einmalig einrichten
----------------------

a) BIOS: Die BIOS-Datei aus deiner eigenen PS2 (4 MB, meist .bin) in den
   Ordner "bios" kopieren.

b) Spiel: Dein Abbild von Fate/unlimited codes (SLPM-55108, von deiner
   eigenen Disc) in den Ordner "game" kopieren. Erlaubt sind .iso, .chd,
   .cso und .bin/.cue. Der Dateiname ist egal.

c) Controller: Ein Xbox-/XInput-Controller wird normalerweise automatisch
   erkannt. Falls die Tasten nicht reagieren: "Einstellungen.bat" starten,
   dort unter Einstellungen > Controller nur den Controller-Port 1 belegen.
   Sonst bitte nichts an den Einstellungen aendern, beide Spieler muessen
   exakt dieselben benutzen.

d) Nur der HOST: Im Router eine Portfreigabe einrichten:
   UDP-Port 7000 an die lokale IP-Adresse des eigenen PCs.
   Der andere Spieler (Join) braucht keine Portfreigabe.

Beim ersten Start fragt die Windows-Firewall nach, ob PCSX2 ins Netzwerk
darf: bitte "Zulassen" waehlen (private und oeffentliche Netzwerke).

Hinweis: Windows SmartScreen kann beim ersten Start warnen, weil die Dateien
nicht signiert sind ("Weitere Informationen" > "Trotzdem ausfuehren").


2. Spielen
----------

Host (Spieler 1):
    "Host.bat" starten. Dem anderen Spieler die eigene oeffentliche
    IP-Adresse sagen (z. B. auf wieistmeineip.de nachsehen).

Join (Spieler 2):
    "Join.bat" starten und die IP-Adresse des Hosts eingeben.

Jedes Spiel startet automatisch im Schnelldurchlauf bis zur
Charakterauswahl von "Vs. 2P", mit allen Charakteren freigeschaltet (dauert
ein paar Sekunden, ohne Ton). Dann wartet es, bis die Verbindung steht. So
lange bleibt das Bild stehen, oben links zaehlt "Netplay: waiting for
player 2 ..." die Sekunden hoch. Das ist normal. Sobald beide verbunden
sind, erscheint "Netplay: connected" und das Spiel laeuft los.
Jeder spielt mit seinem Controller an Port 1, das Spiel ordnet ihn
automatisch dem richtigen Spieler zu.

Beenden: einfach das Spielfenster schliessen.


3. Gut zu wissen
----------------

- Beide Spieler starten das Spiel aus ihrer eigenen Kopie, es wird kein
  Spielstand verschickt. Dafuer muessen BIOS-Version und Spiel bei beiden
  gleich sein. Die Startskripte warnen, wenn dein BIOS eine andere Version
  als beim Organisator ist. Unterscheidet sich das Spiel trotzdem, erscheint
  kurz nach dem Verbinden "the game differs between the players from the
  start". Dann bitte dieselbe BIOS-Version benutzen.
- Memory Cards sind waehrend des Online-Spiels abgeschaltet. Das ist Absicht.
- "Run-Ahead" ist eingeschaltet: Das Spiel reagiert dadurch etwa einen Frame
  schneller auf Tasten. Ist der PC dafuer zu langsam, schaltet es sich selbst
  ab (Meldung oben im Bild), das Spiel laeuft dann normal weiter.
- Erscheint oben "desync detected", laufen die beiden Spiele auseinander.
  Bitte dann Bescheid geben.
- Eingabeverzoegerung (Delay) und Rollback-Tiefe stehen oben in netplay.ps1
  (Delay 1, Rollback 2). Bitte nur in Absprache aendern.


4. Sicherheit
-------------

- Das Programm laedt nichts aus dem Internet nach, startet keine anderen
  Programme und aendert nichts an Windows (keine Registry, kein Autostart).
- Ueber das Netz kommen nur Controller-Eingaben des Gegners an (welche
  Tasten gedrueckt sind), und nur waehrend einer Sitzung.
- Das Paket nur vom Organisator annehmen. Zum Pruefen gibt es eine
  SHA-256-Pruefsumme (Datei ".sha256.txt" neben dem Zip).


5. Nach dem Test
----------------

Bitte die Datei "logs\emulog.txt" an den Organisator schicken. Sie enthaelt
Verbindungs- und Desync-Informationen (keine persoenlichen Daten ausser
Dateinamen).
