MAWARUNCO

Rollback netplay for Fate/unlimited codes

Play the PS2 version online with rollback netcode and lower input latency than on the original console. Free and open source.

Download for Windows View the source

Unofficial PCSX2 fork · Windows 10/11 (64-bit) · You need your own PS2 BIOS and your own copy of the game.

Features

Built for online matches

Rollback netplay

Direct connection, no VPN. The host forwards one UDP port; joining needs nothing. The host sets input delay and rollback depth for the room.

Rooms

Open a room, with a code if you like, or join one from the list with a click. No IP addresses to type, and the list never shows them.

Low input latency

Input-to-screen latency went from 33.6 ms to 10.6 ms. Run-ahead hides the game's internal lag, offline and online.

Straight to character select

No savestates to share. The game boots straight to Vs. 2P or Practice, with all characters unlocked.

Your buttons, always

Set the game's button config once in the start window. You keep your layout as player 1 or player 2.

Player names

Your names appear above the health bars, next to the win counter.

Simple setup

An installer that needs no admin rights. It asks for your BIOS and game, and updates keep your settings.

How to play

From download to first match

  1. InstallDownload Mawarunco-Setup from the latest release and run it. Choose your PS2 BIOS file and your disc image of Fate/unlimited codes.
  2. Set upStart Mawarunco. Under Button config, set up your controller and buttons. Under Online, enter your name.
  3. Host or joinUnder Rooms, create a room or join one from the list. Or connect directly: the host clicks HOST and shares their public IP address, the other player enters it and clicks JOIN. The host forwards UDP port 7000 in their router.
  4. FightBoth games boot to character select. Both players need the same Mawarunco version and the same BIOS version.

Security and transparency

Open source, so you can check it

  • Netplay sends only controller input. It opens one UDP port during an online session, for a short handshake and then controller input and checksums. Received input is only used as button values.
  • The room list never shows IP addresses. It talks to the lobby over HTTPS only while you look at rooms or host one. A host's address goes only to the one player who joins, and is deleted when the room closes.
  • Nothing is downloaded or started. No other programs, no registry changes, no autostart. The PCSX2 auto updater is turned off.
  • No game files included. No BIOS, disc image or game data are in the repository or the downloads.
  • Releases you can verify. Every release is built from a tagged commit, with SHA-256 checksums for every file.

Details, with links to the code to check: README on GitHub.

FAQ

Questions

Where do I get the BIOS and the game?

Dump them from your own PS2 and your own disc. Mawarunco does not include or link to them.

Windows warns me about the installer.

The files are not code-signed, so SmartScreen may warn. Click "More info", then "Run anyway". You can compare the file with the SHA-256 checksum on the release page.

Do I need to forward a port?

Only the host does: UDP 7000. The joining player needs nothing.

The game desynced. What now?

Check that both players use the same Mawarunco version and the same BIOS version. Mawarunco warns if the BIOS versions differ. If it still happens, open an issue on GitHub and attach both players' logs folders.

Is this the official PCSX2?

No. Mawarunco is an unofficial fork made for one game. Please do not report problems with it to the PCSX2 team.
